05Humanoid navigation pilot

A useful prior.
Not yet a policy.

Three collision-avoidance prompts × seeds 17–19. These are open-loop generated videos, scored for exact ordered behavior—not closed-loop robot trials.

Strict temporal completion 0/9

Every inference job produced a valid clip. None showed all requested agents, geometry, action phases, and final state in the correct order.

What the pilot says

Scene ingredients transfer before task structure.

The base model often renders a humanoid, box, pedestrian, or barrier, but does not reliably compose approach, avoid or yield, and recovery into one clip. That is the clearest signal for domain video SFT followed by action-policy training.

06Reproduce locally

Run the same path.

No web framework and no hosted services. Serve this page or reproduce the inference directly from the repository.

Optimized T2I
COSMOS_VAE_CPU_OFFLOAD=1 LD_LIBRARY_PATH='' \
python -m cosmos_framework.scripts.inference \
  --parallelism-preset=latency \
  -i inputs/omni/t2i.json \
  -o outputs/edge_int8wo \
  --checkpoint-path=Cosmos3-Edge \
  --quantization-method=int8wo \
  --use-torch-compile --no-guardrails --seed=0
